# 工具 Tab 条优化方案

> 现状：P3 Tab 多开（`_TabStrip`）——42px 高、横向滚动、激活态仅靠
> `primaryContainer@0.6 / surfaceContainerHigh@0.5` 的浅色差区分。
> 本文从视觉层级、连接感、动效、溢出处理、桌面交互五个维度给出优化方案。

## 一、现状诊断

| 维度 | 现状 | 问题 |
|---|---|---|
| 激活识别 | 激活/未激活仅 0.6 vs 0.5 透明度差 | 对比度不足，一眼难辨当前 Tab |
| 与内容区关系 | 1px 边框硬切，激活 Tab 与下方内容无连接 | 缺少"Tab 从属于内容"的锚定感 |
| 动效 | 切换/关闭/新增均为硬切换 | 桌面专业感缺失，交互生硬 |
| 空间 | 关闭按钮常显，挤压标题；标题无截断 | 长名工具（如"文本格式化"）拥挤 |
| 溢出 | 仅横向滚动，无方向提示 | Tab 多时无感知，易"迷路" |
| 桌面惯例 | 无 Ctrl+W / Ctrl+Tab / 中键关闭 | 与已上线的 Ctrl+K/F/, 体系不一致 |
| Token | 硬编码 alpha 值，未走设计体系 | 与主题/深浅色联动弱 |

## 二、设计原则

1. **激活即锚定**：激活 Tab 必须与下方内容形成视觉连续，像浏览器标签一样"长在"内容上。
2. **三态清晰**：默认 / hover / 激活，三个状态在任意深浅色主题下对比度均 ≥ 3:1。
3. **动效服务于位置感**：切换时让用户知道"我从哪来、到哪去"，而非装饰。
4. **遵循桌面惯例**：快捷键、中键、右键菜单——工具越多越依赖肌肉记忆。
5. **一源设计**：全部走 AppSemanticTokens / AppThemeSeed，不做硬编码色值。

## 三、方案分层

### P0 · 视觉层级重构（核心，先行）

**浏览器式 Tab 锚定**
- 激活 Tab：圆角改为 `顶部 10 / 底部 0`，底色与内容区 `surfaceContainerLowest` 一致，
  且**移除其底部边框**——激活 Tab 与 Pane 无缝衔接，形成"纸片"连接；
  未激活 Tab 保持全圆角 10，与激活态形成「站起 / 躺平」的层级差。
- 激活指示：Tab 顶部 2px 品牌绿（`AppThemeSeed.primary`）圆角指示条，
  比底色差异更明确、也更贴近品牌色体系。

**三态色彩（走主题）**
| 状态 | 底色 | 文字 | 辅助 |
|---|---|---|---|
| 默认 | `surfaceContainerHigh` | `onSurface` | icon `onSurfaceVariant` |
| hover（桌面） | `surfaceContainerHighest` | `onSurface` | 关闭按钮显现 |
| 激活 | `surfaceContainerLowest`（与内容同色） | `onSurface` w700 | 顶部绿条 + 底部无缝 |

**尺寸与密度**
- 高度 42 → **44px**（扩大点击区），Tab 内边距 `12 / 8`，间距 6 → 8。
- 标题：`maxWidth 140` + `ellipsis`，杜绝长名撑破。
- 关闭按钮：`iconSize 16`，**hover 时显现**（桌面 `MouseRegion`），触屏设备常显；
  与标题间距 4。

### P1 · 动效与交互增强

**切换动效**
- 顶部激活指示条：`AnimatedPositioned` 横向滑动（200ms `easeOutCubic`），
  切换时指示条"滑到"新 Tab——位置感最强、开销最小（单条动画，无页面级重建）。
- Tab 切换淡入：激活 Tab 内容 `FadeTransition` 120ms（与 Pane 现有 220ms 保持节奏一致）。

**新增 / 关闭动效**
- 新 Tab：`fade + 轻微 slide-up` 160ms 入场。
- 关闭：120ms fade-out 后移除，邻居平滑补位（`AnimatedSwitcher` 或 `AnimatedList`）。

**溢出处理**
- `ScrollController` 监听：Tab 溢出时左右出现**渐变遮罩**（品牌绿 8% → 透明），
  提示可继续滚动；滚到端部遮罩自动消失。
- 溢出后自动滚动到激活 Tab（`ensureVisible`），避免打开新工具后 Tab 被挤出视野。

**桌面快捷键（与 Ctrl+K/F/, 同体系）**
| 快捷键 | 行为 |
|---|---|
| `Ctrl+W` | 关闭激活 Tab（无 Tab 时忽略） |
| `Ctrl+Tab` | 循环切换下一个 Tab |
| `Ctrl+Shift+Tab` | 循环切换上一个 Tab |

### P2 · 进阶（按需）

- **拖拽排序**：横向 `ReorderableListView`，按住 Tab 拖拽调整顺序（桌面鼠标场景）。
- **中键关闭**：`Listener` 捕获鼠标中键，浏览器惯例。
- **右键菜单**：关闭 / 关闭其他 / 关闭全部。
- **多实例 Tab**：同一工具开多个（需 Session key 化，属 P3 多开升级，单列评估）。

## 四、验收标准

- [ ] 任意深浅主题下，激活 Tab 一眼可辨（信息对比 ≥ 3:1）
- [ ] 激活 Tab 与内容区视觉连续，无 1px 断裂感
- [ ] 切换 / 新增 / 关闭均有动效且不卡顿（无整条重建）
- [ ] 20+ Tab 时溢出可滚动，左右渐变提示正确、自动跟随激活
- [ ] Ctrl+W / Ctrl+Tab 生效；移动端不受影响
- [ ] `flutter analyze` 0 issues；桌面端构建、启动正常

## 五、实施顺序

1. **P0**：视觉重构（锚定式激活态 + 三态 + 尺寸/截断）——一次性到位
2. **P1**：指示条滑动 + 开关闭动效 + 溢出渐变 + 快捷键
3. **P2**：拖拽 / 中键 / 右键菜单（视需要）
